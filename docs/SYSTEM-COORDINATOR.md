# Координатор системного режима

`NetworkHelperClient` поддерживает heartbeat каждые три секунды независимо от WPF-таймеров. Release отменяет ожидание очередного heartbeat, дожидается уже начатого обмена и запрашивает завершение lease. При потере ответа после Acquire идентификатор остаётся неподтверждённым: клиент не объявляет сеть восстановленной только потому, что подтверждение не пришло. Сбой heartbeat закрывает pipe и уведомляет координатор вне задачи обмена.

`SystemTunnelSession` — отдельная асинхронная граница. Запуск: закреплённый профиль → локальное ядро → lease helper → Running. Остановка: Release helper → остановка ядра → Idle только при подтверждённом Released. Ошибка или незавершённый откат даёт RecoveryRequired. Отмена старта не отменяет очистку. Завершение ядра и потеря связи с helper запускают очистку. Он ещё не подключён к рабочему WPF-окну: прежний ITunnelController.Stop синхронный и не должен блокировать окно ожиданием привилегированного IPC.

`TunnelEndpoints` разрешает адрес входного узла до TUN и закрепляет выбранный IP в копии outbound. Исходный профиль сохраняется; TLS SNI сохраняется или заполняется исходным именем. Все полученные точные IP передаются как исключения маршрута. Loopback, link-local, multicast и чрезмерный список отклоняются. Отдельный XHTTP downloadSettings пока отклоняется для системного режима, поскольку может требовать дополнительных адресов исключения.

`SingBoxTunConfig` строит собственную конфигурацию без профиля или ключей: TUN → SOCKS 127.0.0.1 → уже запущенный core. DNS HTTPS направлен через тот же SOCKS, проверка TLS включена, UDP отклоняется после перехвата DNS. IPv4/IPv6 исключения — только /32 и /128 адресов узла. Синтаксис проверяется закреплённым sing-box 1.14.3 через check, с проверкой хеша executable и без переменных XRAY_/SING_ из окружения.

Реальный путь данных и владение созданными core маршрутами/DNS ещё не проверены на VM. Поэтому Windows backend, установка привилегированного helper, kill switch и переключатель системного режима пока не заявляются готовыми. VM-комплект запускает отдельный экспериментальный sing-box, а не объединённую production-сессию helper+журнал. Подробности — [комплект VM](../vm-kit/README.md).
