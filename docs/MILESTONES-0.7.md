# Контрольные точки 0.7

Репозиторий Git создан локально внутри windows-client. Ничего не публиковалось во внешний сервис; глобальная конфигурация Git не менялась. Коммиты сделаны с локальным именем Codex для этой операции.

1. `e801434` — исходная версия 0.6.2: интерфейс, ядра, DPAPI и журнал восстановления. Исходники и документация; пользовательские состояния и тестовые бинарники не включены.
2. `51d3911` — IPC: ограниченные сообщения, явный ACL User SID, проверка процесса на обеих сторонах, heartbeat deadline и восстановление после разрыва; 75 функциональных и 22 WPF-проверки.
3. `3c9392a` — асинхронный координатор, heartbeat-клиент, закрепление IP, проверяемая конфигурация TUN и VM-комплект. Отдельный архитектурный набор: 33 проверки.
4. Коммит выпуска 0.7: документация, полный прогон 85 функциональных / 22 WPF-проверок, состав архива и проверка распакованного комплекта. Его идентификатор доступен в git log.

## Граница выполненного

Реализованы контроллеры и контракты до Windows backend, проверены реальные локальные pipes и процессы, журнал проверен на синтетическом backend, TUN-конфигурация принята закреплённым core. Скрипт VM-комплекта проверен в режиме подготовки без изменения сети.

Отдельной VM сейчас нет. Поэтому реальная передача через TUN, владение маршрутами/DNS, аппаратный сбой, перезагрузка и cleanup core на Windows не проверены. Production Windows backend, установка подписанного привилегированного helper, подключение системного режима к WPF и kill switch остаются работой после получения результатов VM. VM-скрипт — отдельный эксперимент, не скрытая активация этих возможностей.

Бинарники ядер и локальные артефакты сборок не хранятся в Git. Сборка требует исходных app/tools и vendor-кэша, описанных в THIRD-PARTY.md; Git-репозиторий пока не является самодостаточной поставкой ядер. Несвязанные старые файлы не добавляются и не удаляются.
