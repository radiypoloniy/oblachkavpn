# Установщик — 14 октября 2026

`.\build-installer.ps1` собирает `dist\Oblachka-setup-<версия>-<ревизия>.exe` (Inno Setup 6, около 86 МБ). Сценарий — `installer\oblachka.iss`.

## Что внутри

- Самодостаточная сборка: .NET 10 встроен, ставить runtime тестерам не нужно. Ядра — из проверенной сборки `app-v09` (`.\build.ps1`), PDB не кладутся, тестового кода нет.
- Установка требует прав администратора и всегда идёт в `Program Files\Oblachka`: выбор папки отключён, потому что сетевая служба регистрируется только оттуда (см. [NETWORK-SERVICE.md](NETWORK-SERVICE.md)).
- Ярлык в «Пуске», по желанию — на рабочем столе. После установки окно запускается от имени пользователя, а не администратора.
- Запись в «Программах и компонентах» с версией.

## Служба при установке, обновлении и удалении

| шаг | что происходит |
|---|---|
| установка | после копирования файлов — `Oblachka.exe --install-service`. Отказ не валит установку: окно работает с помощником через UAC и прямо об этом говорит |
| обновление | до замены файлов — `--uninstall-service` прежней версии: её остановка снимает сессию и возвращает сеть; открытое окно закрывается через Restart Manager; папка очищается, новые файлы, новая служба |
| удаление | сначала `--uninstall-service` (сеть возвращается), потом закрываются окна, удаляются файлы и `ProgramData\Oblachka`. Подписки и настройки пользователя в `LocalAppData` остаются |

Процесс службы нигде не убивается: тогда фильтры защиты остались бы до перезагрузки.

## Тихая установка

```
Oblachka-setup-0.9.1-xxxxxxx.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
"C:\Program Files\Oblachka\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

Установщик и программа не подписаны (решение отложено). Windows SmartScreen при первом запуске покажет «Windows защитила ваш компьютер» — нужно нажать «Подробнее» → «Выполнить в любом случае». Тестерам это стоит сказать заранее и прислать SHA256 файла.

## Проверено на стенде

Установщик `Oblachka-setup-0.9.1-cbf29e5.exe`, тихий режим, чистая VM без прежней установки.

| сценарий | результат |
|---|---|
| установка | код 0; служба Running, Auto, LocalSystem; ярлык в «Пуске»; запись в «Программах» 0.9.1; .NET внутри |
| окно самодостаточной сборки | запускается |
| перезагрузка | служба поднялась сама, фильтров 0, интернет есть |
| полный прогон `--system-tunnel-check` через установленную службу | код 0 |
| окно убито при подключении | фильтров 14, интернета нет |
| обновление поверх в этот момент | код 0; прежняя служба снята — фильтров 0, интернет есть; новая служба Running; лишние файлы прежней установки удалены |
| удаление при открытом окне | код 0; служба удалена, окно закрыто, фильтров 0, интернет есть; папка, `ProgramData\Oblachka`, ярлык и запись в «Программах» удалены |

Тестовый клиент для прогона на стенде клали в папку установки отдельно, опубликованным самодостаточно; в установщик он не входит.

Не проверено: мастер установки в обычном (не тихом) режиме глазами, обновление при открытом окне с активным подключением (закрытие через Restart Manager), установка без сети, Windows 10.
