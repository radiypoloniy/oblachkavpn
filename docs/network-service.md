# Сетевая служба

Служба `OblachkaNetwork` работает от SYSTEM и делает то, на что у окна нет прав: поднимает TUN, меняет маршруты и DNS, ставит фильтры WFP. Ставит её установщик. Без службы (например, в сборке `out\app`) окно запускает помощника с запросом UAC, а внутри та же сетевая сессия.

## Поведение

- В режиме «Весь компьютер» прав администратора при каждом подключении не спрашивают.
- **Аварийное завершение окна не снимает защиту.** Служба оставляет сессию: туннель без ядра окна ничего не несёт, фильтры держат сеть закрытой, утечки мимо VPN нет. Снимают её «Восстановить сеть», новое подключение, остановка службы или перезагрузка.
- Штатный выход из приложения останавливает подключение и возвращает сеть.

## Граница доверия

Служба работает от SYSTEM, поэтому:

- **Ставится только из Program Files.** `Oblachka.exe --install-service` отказывает (код 3), если exe лежит в папке, куда пишет пользователь. Иначе любая его программа подменила бы `Oblachka.exe` и получила SYSTEM.
- **Подчиняется только своей копии.** По PID клиента канала служба определяет путь его exe. Допустимы только `Oblachka.exe` и `Oblachka.Tests.exe` из папки самой службы, а писать туда может только администратор.
- **Окно проверяет службу.** PID сервера канала должен совпасть с PID службы по данным диспетчера служб, поэтому программа, занявшая имя канала раньше, не пройдёт.
- **Канал только для локальных пользователей.** ACL: SYSTEM — полный доступ, INTERACTIVE — чтение и запись, NETWORK — запрет.
- **Журнал в ProgramData с собственными правами.** SYSTEM и администраторы — полный доступ, пользователи — только чтение. Папку, созданную до службы кем-то без прав администратора, служба пересоздаёт, чтобы журнал нельзя было подложить.

Не закрыто: программа того же пользователя может управлять запущенным окном (отладка, внедрение кода), как у любого клиентского VPN. Подписи Authenticode пока нет.

## Протокол канала

Каждое сообщение — четырёхбайтная длина (little-endian) и JSON до 8192 байт. Обязательные поля: версия, `RequestId`, операция и аренда (`Lease`). Неизвестные и повторные поля отклоняются.

| команда | что делает |
|---|---|
| `Acquire` | применить сетевую сессию: адреса входа, режим, вход прямого трафика ядра |
| `Heartbeat` | продлить аренду (клиент шлёт каждые 3 с; без сообщений 15 с — откат) |
| `Release` | снять свою сессию и вернуть сеть |
| `Recover` | снять сессию, оставленную прежним владельцем |
| `Repair` | исправление из «Сети Windows» (сброс прокси, DNS и т. п.) |

В аренде нет ключей, подписок, путей запуска или команд оболочки, только ограниченный сетевой запрос. Ответы не содержат текста внутренних исключений.

## Команды

| команда | что делает | коды выхода |
|---|---|---|
| `Oblachka.exe --install-service` | регистрирует службу для этой копии, автозапуск, перезапуск при сбое | 0; 2 нет прав; 3 не Program Files; 4 отказ SCM |
| `Oblachka.exe --uninstall-service` | останавливает (сеть возвращается) и удаляет | 0; 2; 4 |
| `Oblachka.exe --network-service` | точка входа для диспетчера служб | — |
