# Code signing policy / Правила подписи кода

Free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by [SignPath Foundation](https://signpath.org/).

_Черновик: действует после того, как SignPath Foundation одобрит проект. До этого установщики Облачки не подписаны (Authenticode), а обновления подписаны ключом разработчика — см. ниже._

## Что подписывается

- Установщик `Oblachka-setup-*.exe` и программы, которые собраны из этого репозитория: `Oblachka.exe`, `Oblachka.dll`, ядро туннеля `oblachka-core.exe`.
- Сборка идёт только на GitHub Actions (`.github/workflows/release.yml`) из тега `vX.Y.Z` в этом репозитории. Собранное на чужих машинах не подписывается.
- Ядра Xray и sing-box входят в установщик как есть, от их авторов: Облачка их не меняет и своей подписью не подписывает. Версии и контрольные суммы — в [THIRD-PARTY.md](../THIRD-PARTY.md).

## Подпись обновлений

Кроме подписи Windows, каждый выпуск подписан отдельным ключом разработчика (ECDSA P-256), которого нет ни на GitHub, ни в SignPath. Облачка ставит обновление, только если подпись сходится (`src/App/ReleaseSignature.cs`).

## Конфиденциальность

Облачка не собирает телеметрию. Что и куда уходит из программы — в разделе [«Конфиденциальность» README](../README.md#конфиденциальность).
## Что Облачка меняет в системе

Установщик ставит сетевую службу «Облачка» (нужна для режима «Весь компьютер»): она поднимает виртуальный сетевой адаптер и фильтры Windows (WFP), которые не выпускают трафик мимо VPN. Всё это снимается при выключении VPN и полностью — при удалении программы через «Установка и удаление программ».
