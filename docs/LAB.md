# Стенд RoutePilot 0.4

Стенд запускается явно из PowerShell. Каждый образец запускает отдельный процесс ядра, выполняет HTTP GET через его SOCKS и останавливает процесс. Ядра и профили чередуются между повторами. Маршруты, DNS, прокси Windows и firewall не меняются.

Скопируй `lab-plan.example.json` в новый файл и замени вымышленные профили на отдельные тестовые профили. В `profiles` допустимы VLESS-ссылки, Xray outbounds и нативные sing-box VLESS/Hysteria2 outbounds. План содержит секреты: в архив приложения он не включается. Обезличенный отчёт использует только индексы профилей; соответствие индекс → профиль остаётся в твоём плане.

```powershell
$appDirectory = Join-Path $PWD 'app-v04'
$planPath = Join-Path $PWD 'my-lab-plan.json'
$reportPath = Join-Path $PWD ('lab-' + (Get-Date -Format 'yyyyMMdd-HHmmss') + '.json')
$run = Start-Process -FilePath (Join-Path $appDirectory 'RoutePilot.exe') -ArgumentList @('--lab', ('"' + $planPath + '"'), ('"' + $reportPath + '"')) -WindowStyle Hidden -PassThru -Wait
$run.ExitCode
```

В распакованном архиве укажи его корень как `$appDirectory`. JSON и соседний CSV создаются с запретом перезаписи. При неверном плане возвращается код 4, сетевой прогон не начинается. Код 0 — все запросы успешны, 2 — есть отказы, 3 — закончился общий бюджет 10 минут. При принудительном завершении контроллера Job Object останавливает ядро; полного отчёта в этом случае может не быть.

Ограничения: 1–8 профилей, 1–10 повторов, интервал 0–10000 мс, HTTPS-адрес проверки без учётных данных/фрагмента. HTTP разрешён только внутренним loopback-тестам. Сайт проверки должен быть выбран тобой; GET и его путь действительно будут запрошены. До десяти минут на весь прогон; задержка запуска/проверки дополнительно ограничена Engine.

`Success` — успешные HTTP-заголовки; `TargetResponse` — HTTP-ошибка сайта проверки; `Reachability` — запрос не выполнен; `CoreRejected` — конфигурация/запуск отклонён; `CoreStopped` — ядро остановилось во время проверки; `StartupTimeout` — запуск истёк; `Canceled` — общий бюджет закончился. Сырой журнал и текст исключений ядра не экспортируются.

`StartupMilliseconds` включает проверку конфига и готовность SOCKS. `RequestMilliseconds` включает установку соединения и получение HTTP-заголовков. Медиана считается только по успешным запросам; `SuccessRate` — доля успешных образцов. Это не измерение ping, скорости загрузки, DPI-устойчивости или длительных соединений. Hysteria2 имеет холодный запуск QUIC в каждом образце — учитывать при сравнении.

Для начала: одинаковый сайт, одинаковое число повторов, отдельные прогоны домашней сети и мобильного подключения; затем сравнение с Throne на том же узле. Сон/смена сети, длинные загрузки и реальные операторские блокировки остаются отдельными сценариями.
