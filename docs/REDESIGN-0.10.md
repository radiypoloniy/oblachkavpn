## Отступления от макета

- Справа в шапке добавлены «Свернуть» и «Закрыть»: без системного заголовка иначе окно не свернуть.
- «Без VPN — без интернета» показан только в режиме «Весь компьютер»: прокси защитить весь компьютер не может, выключенный переключатель обещал бы то, чего нет.
- Статус «Защищено» — только для «Весь компьютер»; в режиме прокси — «Подключено».
- Приветствие с подключением без ключа не сделано: нужен бэкенд выдачи ключей (вторая версия). Первый экран — «Вставьте ключ».
- «Продлить» скрыт, пока в `ServiceBrand.SupportUrl` нет адреса.

## 14 октября, вечер: отклик, перенос подписок, гонка остановки

- **Отклик серверов при запуске** (`ServerPing`): время TCP-рукопожатия с каждым узлом, восемь параллельно, без ядра. Запускается при старте, после загрузки подписки, при открытии «Всех серверов» и раз в 10 минут. Под «Весь компьютер» не обновляется: защита пропускает к узлам только ядро, а запрет на этом компьютере не считается «нет ответа». Свежий полный замер «Проверить все» важнее отклика; автовыбор и сортировка учитывают оба. Hysteria2 (UDP) пропускается.
- **Перенос из других клиентов** (`ForeignClients`, `WinSqlite`): экран ключа показывает подписки из Happ (журнал обновлений — база зашифрована), Throne, Hiddify, v2rayN (SQLite через системный winsqlite3.dll), NekoBox, v2RayTun, FlClash(X), Clash Verge. Нажатие загружает подписку и подключает. Ключ на экран не выводится — только хост и четыре последних знака. Только HTTPS-адреса; отдельные профили без подписки не переносятся.
- **Исправлено: «Выключить» во время запуска «Весь компьютер» оставлял сеть закрытой**, а окно показывало «Не подключено». Отмена посреди Acquire закрывала канал, служба считала окно погибшим. Теперь Acquire доводится до конца, затем обычный Release. «Защищено» — только после подтверждения туннеля службой.

Проверено: самопроверки 192, UI 36; на VM через установщик 5b9d62b — перенос из Happ → «Защищено», остановка через 0,3 / 0,8 / 1,5 с после включения и после «Подключить лучший» — ядро снято, фильтров 0, интернет есть. Отклики на VM проверить нельзя, пока на хосте включён «Весь компьютер» Облачков: VirtualBox на хосте тоже не пускают к узлам сервиса.
