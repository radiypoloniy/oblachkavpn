# Установщик

`.\build-installer.ps1` собирает `dist\Oblachka-setup-<версия>-<ревизия>.exe` (Inno Setup 6, около 90 МБ). Сценарий — `installer\oblachka.iss`.

## Что внутри

- Самодостаточная сборка: .NET 10 встроен, ставить runtime не нужно. Ядра берутся из `out\app` (`.\build.ps1`), PDB и тестового кода нет.
- Установка требует прав администратора и всегда идёт в `Program Files\Oblachka`. Выбора папки нет, потому что сетевая служба регистрируется только оттуда (см. [network-service.md](network-service.md)).
- Ярлык в «Пуске», по желанию — на рабочем столе. После установки окно запускается от имени пользователя, а не администратора.
- Регистрация ссылок `oblachka://` для добавления подписки из браузера.

## Служба при установке, обновлении и удалении

| шаг | что происходит |
|---|---|
| установка | после копирования файлов — `Oblachka.exe --install-service`. Если не вышло, установка не прерывается: окно работает с помощником через UAC и прямо об этом говорит |
| обновление | до замены файлов — `--uninstall-service` прежней версии: остановка снимает сессию и возвращает сеть. Открытое окно закрывается через Restart Manager, папка очищается, ставятся новые файлы и новая служба |
| удаление | сначала `--uninstall-service` (сеть возвращается), потом закрываются окна и удаляются файлы и `ProgramData\Oblachka`. Подписки и настройки в `%LOCALAPPDATA%\Oblachka` остаются |

Процесс службы никогда не убивается принудительно: иначе фильтры защиты остались бы до перезагрузки.

## Тихая установка

```
Oblachka-setup-0.13.0-xxxxxxx.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
"C:\Program Files\Oblachka\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```

## Обновление из приложения

«Приложение → Обновления» сверяется с последним релизом этого репозитория на GitHub: сама раз в 12 часов или по кнопке. Установщик скачивается только по нажатию «Обновить». Его размер и SHA256 сверяются с `digest`, который GitHub вычисляет при загрузке файла в релиз. Допускаются только адреса `github.com/radiypoloniy/oblachkavpn/releases/download/…` и хранилище файлов GitHub.

Затем запускается тот же установщик с ключами `/SILENT /SUPPRESSMSGBOXES /NORESTART /RELAUNCH=1`. Windows спрашивает права администратора, установщик ставит новую версию поверх и открывает окно. Сетевая служба ничего скачанного не запускает: обновление всегда проходит через запрос прав.

Чтобы обновление нашлось, в релиз нужно загрузить файл `Oblachka-setup-<версия>-<ревизия>.exe` с тегом `v<версия>`.

## Подписи нет

Установщик и программа пока не подписаны. При первом запуске SmartScreen покажет «Windows защитила ваш компьютер»: нужно нажать «Подробнее» → «Выполнить в любом случае». Подлинность файла можно проверить по SHA256 из описания релиза.
