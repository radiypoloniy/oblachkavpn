# Сторонние компоненты

## Xray-core

Версия закреплена: **26.9.9**, windows/amd64, commit `52a412d`, Go `go1.27.1` по выводу бинарника. SHA-256 `tools/xray.exe`:

```text
0D0FC0EA2B05641ACB78C01FC36AD694E7B029861B2D5EB93DA0E3E9FDA9A98F
```

Бинарник скопирован из уже имевшегося в рабочей папке диагностического набора Xray 26.9.9. Он не изменён. Его соответствие официальному подписанному релизному артефакту дополнительно не установлено; SHA фиксирует локальную копию, а не подтверждает происхождение поставщика. Перед публичным выпуском надо воспроизводимо получить официальный артефакт и сверить опубликованные контрольные суммы.

- Проект и исходники: https://github.com/XTLS/Xray-core
- Исходники закреплённого релиза: https://github.com/XTLS/Xray-core/tree/v26.9.9
- Лицензия MPL-2.0: в комплекте `tools/LICENSE-Xray`.

RoutePilot запускает Xray отдельным процессом. Код ядра не модифицируется и не включается в собственные исходники. Публикация клиента требует проверки всех условий распространения используемых бинарников; описание здесь фиксирует фактический состав прототипа.

## sing-box

Закреплён официальный релиз **1.14.3**, windows-amd64. Архив получен с GitHub SagerNet/sing-box; SHA256 совпал с `digest` GitHub Release API. Архив и оба распакованных бинарника проверяются при сборке. Запись происхождения: `vendor/sing-box-1.14.3/provenance.json`.

- Релиз: https://github.com/SagerNet/sing-box/releases/tag/v1.14.3
- Исходники: https://github.com/SagerNet/sing-box/tree/v1.14.3
- SHA256 архива: `D8B86EF58936DBA9230EC6A57FFA4243933F3C14EF4809828B6C553440ED1518`.
- SHA256 sing-box.exe: `5C19BB3F8C12D4E85B3D47FE63123A7624B314B58DD7A8E32F51004F1C4D2FAF`.
- SHA256 libcronet.dll: `3217C6260FBCA5F16072E0B79735742F40109A63BB0FF88FD6B96DD6B54A2928`.
- Лицензионное уведомление поставщика `tools/LICENSE-sing-box`, полный GPL `tools/COPYING-GPL-3.0`. В уведомлении поставщика также есть условие использования имени проекта. libcronet.dll включён как файл официального комплекта, без изменения.

Это локальная тестовая сборка. Перед распространением аудитории нужно подготовить соответствующие исходники/предложение исходников в форме, отвечающей GPL, проверить уведомления и лицензии зависимостей (включая libcronet), а также подтвердить происхождение Xray. Одна ссылка на GitHub не считается выполнением всех условий распространения. Запуск отдельным процессом сам по себе не заменяет проверку лицензий.

## .NET Runtime

WPF и Windows Forms входят в .NET Desktop Runtime и не распространяются внутри этого framework-dependent архива. Нужен .NET 8 Desktop Runtime x64: https://dotnet.microsoft.com/download/dotnet/8.0

## Geo-базы

В рабочем `app/tools` сохранены ранее скопированные geoip.dat и geosite.dat. Текущие генерируемые конфигурации на них не ссылаются. В распространяемый архив они не включаются, чтобы не добавлять непроверенные данные и лицензии.
